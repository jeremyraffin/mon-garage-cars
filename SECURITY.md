# Politique de sécurité

## Signaler une vulnérabilité

Ne pas ouvrir d'issue publique pour un problème de sécurité. Utiliser le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**.

Merci de décrire le problème, les étapes pour le reproduire et son impact potentiel. Ne joindre aucune donnée personnelle ni photo réelle.

## Traitement

Projet personnel maintenu bénévolement : accusé de réception visé sous 7 jours, sans garantie de délai de correction. Les failles touchant les accès ou les données privées sont traitées en priorité.

## Périmètre

Le code de ce dépôt et sa configuration. Les services tiers (Supabase, Cloudflare, Google) relèvent de leurs propres politiques.

## Secrets

Aucun secret ne doit figurer dans le dépôt. Si vous en repérez un, signalez-le de la même façon.
